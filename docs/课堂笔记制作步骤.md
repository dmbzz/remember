# 课堂录音转笔记制作步骤

准备课堂录音或已有转写文本，让有文件访问能力的 AI 助手生成一节课一份的 Obsidian 笔记。录音输入需要可用且已授权的语音转文字能力；已有转写文本可以直接整理。模型、系统和助手产品由使用者选择，每次由当前助手完成生成和核验。

1. 准备独立的输入目录和 Obsidian 库，设置笔记、转写原文归档及处理清单的位置。输入可放录音或 .txt/.md 转写；同一录音及其对应转写应明确关联，避免重复处理。目录含空格、中文或零宽字符时，用文件选择器或枚举取得真实路径。
2. 复制[课堂录音转笔记通用提示词](课堂笔记自动任务模板.md)，填写路径参数；如已确认课程名和上课日期，也可填写。不要把个人目录或凭据提交到公开仓库。
3. 使用录音时，确认助手能读取音频，并配置支持该格式的语音转文字工具。工具缺失、音频无访问权限或格式不支持时，助手应报告原因并停止相关材料的处理。工具确实完成转写后，保留未经润色的原始输出、来源指纹和完整性记录；缺段时先报告，不生成正式笔记。使用已有转写时跳过本步骤，保持输入文本不变。
4. 让助手执行提示词：先按历史台账、原文指纹和已有归档判重，再生成融合式笔记；将原始转写归档并核验后，确认最终笔记完整，再登记成功。同名变更、改名重复、历史缺指纹和中断恢复都应先核对，不能覆盖或重新生成历史笔记。
5. 阅读笔记与报告，重点核对公式、老师原意、待确认内容、自测答案及作业和考试日期。录音转写中的听不清或未录到的板书不能当成已确认事实；发现旧双文件时，保留原件，先查看融合预览再决定是否替换或删除。

融合式笔记把课堂正文与 AI 拓展卡片放在同一文件中，用明显边界区分。每份笔记包含概述、Mermaid 思维导图、课堂知识点、老师强调、事务待办、转写勘误、待确认、学习建议以及 3–5 道自测题和参考答案；公式使用 LaTeX。原始录音和转写保留，勘误只写入笔记，不回写原始材料。

## 路径参数示例

以下是占位示例，使用前替换为当前设备真实设置：

```text
INPUT_DIR = <录音或已有转写输入目录的绝对路径>
VAULT_DIR = <Obsidian 库根目录的绝对路径>
NOTES_DIR = <Obsidian 库根目录>/课堂笔记
ARCHIVE_DIR = <笔记根目录>/转写原文
LEDGER_FILE = <笔记根目录>/00-任务规划/已处理文件清单.md
ASR_TOOL = <处理录音时可用且已授权的语音转文字能力或工具；已有转写可留空>
COURSE_NAME = <可选，已确认的课程名>
CLASS_DATE = <可选，已确认的上课日期 YYYY-MM-DD>
```

这些文档只提供可复制的提示词和使用步骤，不会自动安装语音转文字工具、连接账号、创建计划或修改应用设置。执行前需要能访问所填目录；无法访问或缺少必要能力时，应按实际情况报告并停止相关处理。
