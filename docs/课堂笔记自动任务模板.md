# 课堂录音转笔记通用提示词

把下面的内容复制给具有文件访问能力的 AI 助手，填写路径后使用。输入可以是课堂录音，也可以是已经转写好的文本；每次由当前助手完成处理、生成和核验。本文只提供提示词，不会创建定时任务或修改应用设置。

```text
任务：把课堂录音或已有课堂转写，整理成 Obsidian「融合式单文件」课堂笔记。

【设置】
- INPUT_DIR：录音或已有转写的输入目录（绝对路径）；也可由使用者明确指定本次文件列表。
- VAULT_DIR：Obsidian 库根目录（绝对路径）。
- NOTES_DIR：笔记根目录；默认 VAULT_DIR/课堂笔记。
- ARCHIVE_DIR：原始转写归档目录；默认 NOTES_DIR/转写原文。
- LEDGER_FILE：处理清单；默认 NOTES_DIR/00-任务规划/已处理文件清单.md。
- ASR_TOOL：可选，使用者已配置并授权的语音转文字能力或工具；只有处理录音时需要。不要把工具名占位符当成真实可调用工具。
- COURSE_NAME、CLASS_DATE：可选，使用者已确认的课程名与上课日期；未填写时从材料核对，不猜测。

这些值是参数，使用前替换为当前设备真实设置。路径含空格、中文或零宽字符时，通过系统文件选择器或枚举父目录取得实际路径，不能手打同形路径或误建目录。先确认输入可读、笔记库存在且可写；候选目录不唯一、配置缺失或权限不足时，报告具体问题并停止相关处理，不猜路径、不伪称成功。输入、输出与原文归档目录保持分开，不把个人目录或凭据写入公开文档。

【1. 识别输入与判重】
读取使用者指定的文件，或枚举 INPUT_DIR 内的音频与 .txt/.md 转写。常见音频扩展名可包括 .wav、.mp3、.m4a、.aac、.flac、.ogg、.opus、.wma；是否可处理以当前工具实际支持为准。排除笔记、处理清单、已有归档、生成结果及非课堂材料。音频与其对应转写只算同一份课堂来源，不能各生成一次；无法确认对应关系时列为待确认。

先读 LEDGER_FILE 和已有原文归档，逐份计算输入原始字节的 SHA-256，再决定是否处理：
- 指纹相同且课程、课次、日期、来源无冲突的改名文件记为重复，不重新生成。即使字节相同，若有证据属于不同课次或来源，先标待确认。
- 同名但内容变化，必须核对，不能仅按文件名、大小或修改时间跳过。同一录音重新转写也不能自动覆盖已有笔记。
- 历史清单缺指纹时，先与对应归档核对，确认后才补记；无法核对则标“旧记录待确认”，不能静默当作已处理或新课。
- 只有能证明差异仅是转写生成时间等元数据，且课堂正文、完整性和来源一致，才视为同一份；否则保留双方并报告。

没有可处理的新材料时回复“没有新增课堂材料”；若有扫描错误或待确认项，同时说明，不创建或改写笔记。

【2. 录音先转文字】
已有转写文本直接进入下一步。录音则先确认当前助手能访问实际音频，并具有可用、已授权且支持该格式的 ASR 能力或工具。音频不可访问、格式不支持或缺少转写工具时，明确报告原因并停止这份材料的处理；不根据文件名、课程常识或其他笔记编造转写，也不把音频直接当作已转写成功。

实际执行转写，尽量保留时间戳与可辨认的说话人标记；工具未提供时不得补造。保留未经润色的原始转写输出及音频来源路径、指纹、工具名称和完整性状态。长录音分段时核对分段时间范围、边界和顺序，避免漏段、重复与拼接截断。音频未完整处理或输出明显缺段时，保留已得结果、报告缺口，停止生成正式笔记，不登记成功。

听不清、多人重叠、板书未录入和专业术语存疑的位置标“⚠️待确认”；不要以语言通顺为由改写老师原意。保留源录音，不删除、不改名、不覆盖。已有文本也须保持原始字节不变；后续纠错体现在笔记和勘误表中。

【3. 生成融合式单文件】
完整阅读转写，识别系统讲授知识的主讲人，过滤无关闲聊，保留老师的知识、解释、例题及所有重要课程事务。修正有依据的同音错字，将口述公式还原为 LaTeX；存疑的符号、数值、推导和口误标“⚠️待确认”。逐字引语必须能在转写中找到，有原始时间戳才附时间戳；不能逐字核实的写“老师大意”，不虚构课堂动作、情绪、举例或他人反应。

每节课仅生成一个 NOTES_DIR/<课程名>/<主题>_YYYY-MM-DD.md，主题尽量 3–6 字，日期固定放文件名末尾，不添加“基础版”“拓展讲解版”等后缀。课程与日期应来自使用者确认或材料中的可靠依据，不能用运行当天冒充上课日期。无法确定课程、日期或材料是否属于同一节课时，先报告待确认，暂停该份。保留课程文件夹和相关笔记的 Obsidian 链接；最终目标已存在且非同一次中断恢复时绝不覆盖，无法安全消歧则报告冲突。

文档依次包含：
1. YAML frontmatter：tags 包含“课堂笔记”“课程/<课程名>”“待复习”；确有考点再加“考点”；format 为“融合式（课堂实录 + 拓展讲解）”。
2. 概述 3–5 句；Mermaid mindmap 2–3 层，节点避免括号等易引起语法问题的特殊字符。
3. 按知识点组织的课堂正文，忠实老师原意，保留关键推导、解释与例题。若使用者另行提供可核实的教材等补充材料，注明材料名与页码，不伪装成课堂原话；无法核对时标待确认。
4. 每个有延伸价值的知识点末尾加入 `> [!tip] 💡 拓展｜标题` callout，每行均以 `>` 开头；按需解释为什么、怎么用或在哪章用、易错陷阱。AI 推断与延伸只放卡片，不能冒充老师所说。
5. 老师强调与考点；事务通知与待办独立成节，用 checkbox 记录作业、考试、截止时间、带物品、评价等。相对日期仅在上课日期可靠时换算，并保留原始表述。
6. 转写勘误表、⚠️待确认、学习建议与自测：给出 3–5 道紧扣课堂内容的自测题及参考答案。材料不足时减少题数并说明，不编造题目条件或答案。

写作后由当前助手自行核验事实依据、引语、公式与单位、推导、来源、Mermaid 语法、callout 格式、题目答案、重复/遗漏及通知日期。可使用适用的工具校验；没有解析或渲染工具时说明检查范围，不能宣称已经渲染验证。不要为凑字数删减老师的关键内容。

【4. 归档、登记与恢复】
先保存原文，再登记成功：
- 已有转写：逐字节复制到 ARCHIVE_DIR，保留原扩展名与原始内容；归档后重新计算 SHA-256，必须与输入一致。
- 由录音新转写：先保存工具未经润色的转写文本及可用的原始输出，记录音频来源、音频 SHA-256 与转写文件 SHA-256；笔记中的纠错不得回写原始转写。
- 归档名可用 <课程名>_第N次课_YYYY-MM-DD<原扩展名>；只在课次可确认时使用第 N 次课，否则使用可追溯的来源标识，不臆造课次。归档目标指纹相同可复用，不同则保留双方并报告，不能覆盖。

先在独立临时位置生成并校验笔记、完成原文归档及指纹核对，再安全写入最终新笔记。确认处理中输入未改变、最终笔记与归档均完整后，向 LEDGER_FILE 追加来源相对路径、来源类型及 SHA-256、课程、上课日期、笔记链接、归档链接、处理时间与状态；录音输入同时登记原始转写指纹。保留台账结构和历史记录，每份独立完成，失败说明具体文件和阶段，不登记为成功。

中断重跑时先核对已有笔记、归档与指纹，只有能证明属于同一次处理才恢复或补登；身份不明则暂停，禁止覆盖或重复建档。同一任务仍在运行时不启动第二次写入，报告后退出。

发现历史“基础版 + 拓展讲解版”时先保留原件；需要融合时另做可审阅预览与备份，旧文件的删除或替换须在列出具体文件后由使用者确认。绝不删除源录音、输入转写或已有笔记。

【5. 交付】
逐一列出新笔记完整路径、每节课一句话摘要、录音转写的实际结果与完整性、重要事务及截止时间、待确认内容；涉及重复、跳过、失败或工具缺失时说明文件和原因。没有实际生成、核验并登记成功的成果，不汇报为完成。
```
